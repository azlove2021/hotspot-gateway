① 两台手机的 IP 在哪看
A 手机（开热点这台）
本 App → 仪表盘 → 「本机网卡」，热点那行就是网关 IP，例如 10.247.101.131

B 手机（连热点这台）
设置 → WLAN → 点当前连接 → 看「IP 地址」，一般和 A 同一网段
也可以直接看仪表盘的「B 手机（热点客户端）」列表
② B 手机怎么填代理
只有无 root 代理共享模式才需要手动填，网关模式不用。

安卓
设置 → WLAN → 长按热点 → 修改网络 → 高级选项 → 代理 → 手动
主机名填网关 IP，端口 7891

iPhone
无线局域网 → 热点右侧 ⓘ → 配置代理 → 手动
服务器填网关 IP，端口 7891
③ 能不能用 WiFi 不耗流量
可以。手机支持 WiFi 与热点同时工作（STA+AP 并发）就行。

怎么做
1. 系统设置里连好一个 WiFi
2. 打开热点（顺序反过来也行）
3. 仪表盘「本机网卡」会同时出现 wlan0 和 wlan2
4. 不用改任何配置，默认路由自动切到 WiFi

实测（一加 Ace 2 Pro）
三接口并存，路由自动变成 dev wlan0，两台设备正常翻墙。 手机自己的流量仍走原 WiFi，只有热点客户端被代理。

注意
· 频段错开最好（WiFi 连 5G、热点开 2.4G），同频段速度会砍半
· 少数 ROM 开热点会断 WiFi，那就只能走移动数据
· 切换 WiFi 时 B 手机会断 3–5 秒，之后自动恢复
④ 电脑能不能用
能。

方式一：连 A 手机的热点（推荐）
网关模式下什么都不用设；代理共享模式下设系统 HTTP 代理指向 A 的 IP:7891

Windows：设置 → 网络和 Internet → 代理 → 手动设置代理
macOS：系统设置 → 网络 → 高级 → 代理 → 勾选网页代理与安全网页代理

方式二：电脑连同一个路由器
A 手机连路由器，电脑和 A 同局域网，代理指向 A 的路由器 IP:7891
⑤ 常见问题
界面数据全是「—」
先看手机是不是息屏了。息屏或刚唤醒时 WebView 暂停刷新，解锁后 2–3 秒自动恢复；也可以切一下底部页面强制刷新。

B 手机显示「已连接但无法访问互联网」
Android 联网检测失败，不影响实际使用，浏览器能开网页就没事。

只有部分 App 能上网
代理共享模式下，不认系统代理的 App（部分游戏、Netflix）走不了，这是代理模式的固有限制。要全局就得上 root 用网关模式。

关掉 App 后 B 手机断网
网关模式有 90 秒心跳保护，会主动恢复默认网络，不会锁死。

想换节点
节点页 → 点任意节点即可切换；订阅更新用「导入订阅」或「从 FlClash 同步」。
